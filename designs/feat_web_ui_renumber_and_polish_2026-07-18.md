## Task A: 去编号（结构文字，零测试改动）

**What**: h2 标题和侧栏导航去掉中文数字编号，侧栏改"当日 / 分析"分组。

**根因（为什么"乱"）**: R18 把"当日实战"九/十/十一前置，编号沿用 txt 报告章节号 → 页面物理顺序 零→九→十→...→一→八，编号非单调，产生"乱"的观感。

**How**:

1. **h2 去编号**（report.html 14 处，纯文字替换）:

| 现 | 改 |
|---|---|
| 零、数据完整性检查 | 数据完整性检查 |
| 九、ob_quality 全管线 30 分段胜率汇总 | ob_quality 全管线 30 分段胜率汇总 |
| 十、今日三十分段候选明细 | 今日三十分段候选明细 |
| 十·附、连续入选追踪 (...) | 连续入选追踪 (...) |
| 十·附2、Day 1 三层过滤 (...) | Day 1 三层过滤 (...) |
| 十一、S7/S9 段日内操作建议 (...) [⚠️ fallback] | S7/S9 段日内操作建议 (...) [⚠️ fallback] |
| 一、单因子 IC 数据汇总 | 单因子 IC 数据汇总 |
| 二、单因子分层回测 | 单因子分层回测 |
| 三、因子相关性矩阵 | 因子相关性矩阵 |
| 四、因子筛选结果 | 因子筛选结果 |
| 五、综合因子 4 种权重回测 | 综合因子 4 种权重回测 |
| 六、综合因子与单因子对比 | 综合因子与单因子对比 |
| 七、权重选择结果 | 权重选择结果 |
| 八、股票选股结果 | 股票选股结果 |

2. **侧栏分组**（14 个平铺链接 → 2 组）:
   - **当日**: 数据完整性 / 30 分段胜率 / 候选明细 / 连选追踪 / Day1 三层过滤 / S7/S9 日内操作
   - **分析**: 单因子 IC / 分层回测 / 相关性矩阵 / 因子筛选 / 综合回测 / 因子对比 / 权重选择 / 选股结果
   - 分组间加 `.nav-group` 小字标签（当日 / 分析），样式用现有 `#8b949e` muted 色

**Don't**:
- 不改任何 `id="section-*"` 锚点（测试、JS 滚动、侧边激活全依赖）
- 不改 `_section_*.html` 内部标题（本次只动 report.html 骨架）
- 不删 `[⚠️ fallback]` 等状态标注（那是数据状态，不是编号）

**Why**: 编号引用价值低（报告页是屏幕阅读非打印引用），而"乱"的观感直接消除；分组让"先看当日、后看分析"的 R18 意图显式化，比隐式编号更清晰。

**Verify**: 页面 h2 无中文数字编号；侧栏 2 组；14 个锚点仍可跳转；`pytest test_app.py` 全过（grep 已确认无编号标题断言，零测试改动）。

## Task B: 当前风格精修（CSS，保持暗色玻璃，不引紫）

**What**: 在现有 GitHub 暗色玻璃基础上做一致性精修，不换主题。

**候选优化点（Execute 时逐项核对，只动确定有问题的）**:

| # | 点 | 现状 | 修法方向 |
|---|---|---|---|
| B-a | h2 侧 accent 条 | `inset 4px 0 0 #58a6ff` 蓝 | 保留蓝（不引紫），或改 `#3fb950` 绿呼应数据正色——**执行时二选一，取与 heatmap 主色一致的绿** |
| B-b | h3 全大写 | `text-transform: uppercase` + 绿 `#3fb950` | CJK 不受影响，但英文 label 全大写在中文报告里突兀 → 去 uppercase，保留绿 |
| B-c | `.empty` 重复定义 | L242 白底 `#fafbfc`（浅色残留）+ L480 暗色各一份 | 删 L242 浅色版（暗色主题的浅色残留 bug） |
| B-d | 侧栏分组样式 | 新增 `.nav-group` | 与 B 配套 |

**Don't**:
- 不动 KPI 卡 / 表格 / 热力图配色（E1 刚修到达标，不动）
- 不动响应式断点、sticky、backdrop blur、JS
- 不"顺手"改其它视觉（karpathy §3 surgical）

**Verify**: 浏览器 4 角度截图（顶部 KPI / IC 表 / 热力图 / 整页滚动）确认无浅色残留、无毛边；E1 对比度不回归（复测 cell-* ≥4.5）。
