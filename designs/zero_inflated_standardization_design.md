## 1. 问题定义

### 1.1 现象

price_volume_divergence 在等权8因子综合因子中：
- 名义权重: 12.5%（1/8）
- **实际贡献占比: 22.5%**（Top 10均值）
- 贡献范围: [11.9%, 29.8%]
- ICIR=0.16 是最弱因子，却贡献最大份额

### 1.2 根因

公式 `shrink_signal = max(0, 1 - vol_ratio)` 在 `vol_ratio ≥ 1` 时返回精确 0.0。
- 42% 观察值为精确0（不缩量的股票无背离信号）
- 零值有明确经济含义（中性截断），不是数据噪声

截面标准化 `(v - μ) / σ` 时：
- 42%零值 → μ ≈ 0, σ ≈ 0.015（人为压缩）
- 非零值（如 0.04）→ z = 0.04/0.015 ≈ 2.67
- 正常因子（如 price_position）σ ≈ 0.25，z范围 [-1.8, +2.3]

Winsorize clip ±3σ 截断了极端尾部（-24→-3），但**不修正σ失真**——clip后的z-score仍然反映了零膨胀的放大效应。

### 1.3 受影响因子

零膨胀分布因子清单（需要确认哪些因子有类似问题）：

| 因子 | 零值占比 | 需零值分离？ |
|------|---------|------------|
| price_volume_divergence | 37-42% | **是** |
| volume_price_strength | 1.2-2.8% | 否（<5%阈值） |
| price_position | 0.9-4.3% | 否 |
| 其他因子 | <3% | 否 |

**阈值**: 零值占比 ≥ 5% 的因子触发零值分离标准化。

## 2. 方案A设计——零值分离标准化

### 2.1 第一性原理推导

**前提1**: 零值在 pvd 中是有经济含义的截断信号（"不缩量=无背离=中性"），不是随机噪声。

**前提2**: 截面标准化的目的是衡量"某股票的因子值偏离全截面平均的程度"——z-score越大，信号越强。

**前提3**: 当42%的观察值为精确0时，σ反映的是"全截面的离散度"，但零值组（z≈0）和非零值组（z被放大到±3）之间的差距是σ失真造成的，不是真实的信号强度差异。

**推导**: 零值=中性信号 → z-score应该=0（全截面均值附近）。非零值=有效信号 → z-score应该用**非零值自身的分布**衡量偏离程度。这样才能让z-score反映真实的统计显著性。

**结论**: 零值组 z=0，非零值组用非零值的 μ_nonzero / σ_nonzero 标准化。

### 2.2 具体算法

```python
def standardize_with_zero_separation(group, zero_threshold=0.001):
    """
    零值分离标准化：
    1. 检测零值（|v| < zero_threshold）
    2. 零值 → z = 0（中性信号）
    3. 非零值 → 用非零值自身的 μ/σ 标准化
    4. clip ±3σ（Winsorize）
    """
    zero_mask = group.abs() < zero_threshold
    nonzero_vals = group[~zero_mask]
    
    if len(nonzero_vals) == 0:
        # 全为零值 → 全部 z = 0
        return pd.Series(0.0, index=group.index)
    
    if len(nonzero_vals) <= 1:
        # 非零值不足 → 非零值 z = 0（无法计算σ）
        return pd.Series(0.0, index=group.index)
    
    mu = nonzero_vals.mean()
    sigma = nonzero_vals.std()
    
    if sigma == 0:
        # 所有非零值相同 → z = 0
        return pd.Series(0.0, index=group.index)
    
    # 非零值标准化 + clip ±3σ
    z_nonzero = np.clip((nonzero_vals - mu) / sigma, -3.0, 3.0)
    
    # 组合结果
    result = pd.Series(0.0, index=group.index)  # 零值默认 z=0
    result[~zero_mask] = z_nonzero
    
    return result
```

### 2.3 zero_threshold 选择

- 精确0值检测用 `|v| < 0.001`（而非 `v == 0.0`）
- 原因：浮点精度可能导致"应该为0"的值变成极小非零值（如 1e-15）
- pvd 的值范围 [-0.58, 0.36]，0.001 远小于任何有意义的非零值

### 2.4 触发条件

零值分离标准化**不是对所有因子生效**——只有零膨胀因子才需要：

- **检测方式**: 每日截面中零值占比 ≥ 5%（`_ZERO_INFLATED_THRESHOLD = 0.05`）
- **正常因子**（零值占比 < 5%）：使用原有的 `(v - μ) / σ` + clip ±3σ
- **零膨胀因子**（零值占比 ≥ 5%）：使用零值分离标准化

### 2.5 预期效果

| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| pvd σ | 0.015（全截面） | 0.03（非零值自身σ） |
| pvd 非零值z范围 | [-3, +3]（clip后） | [-2, +2]（自然范围） |
| pvd Top10贡献占比 | 22.5% | ≈12-15%（与ICIR匹配） |
| pvd 600408 z-score | -3.00 | ≈-1.5（取反后） |
| 正常因子 | 不受影响 | 不受影响 |

3. 在每个因子的截面标准化循环中：

## 5. 规范引用

- **M9**: 截面标准化 `factor_std = (factor - μ) / σ` → 扩展为零值分离模式
- **H5**: IC方向由数据决定，不可人为翻转 → 零值分离不翻转方向，只修正σ失真
- **第一性原理**: 零值=中性截断信号 → z=0，非零值用自身分布标准化
