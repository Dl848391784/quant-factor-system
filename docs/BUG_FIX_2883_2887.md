### 问题根因
1. **`groupby('date', group_keys=False).apply()` 行为**：
   - `group_keys=False` 参数会阻止分组键被添加到结果索引
   - 当 `apply()` 返回的 DataFrame 列结构与原数据一致时，`date` 列理论上应该保留
   - 但实际上，`pd.DataFrame(selected)` 在空数据时创建的 DataFrame 可能导致问题

2. **实际执行流程**：
   ```python
   selected_df = score_df.groupby('date', group_keys=False).apply(
       lambda g: get_top_n_with_industry_constraint(g, top_n, max_same_industry, enabled)
   )
   ```
   
3. **关键发现**：当 `get_top_n_with_industry_constraint` 返回数据时：
   - 如果有数据：返回 `pd.DataFrame(selected)`，其中 selected 是包含完整字段（包括 date）的行列表
   - 如果无数据：返回 `pd.DataFrame(columns=expected_columns)`，带有 date 列
   
   **但是**：`groupby().apply()` 合并结果时，如果分组函数返回的是 DataFrame，pandas 会尝试智能合并，可能导致 date 列丢失

4. **防御性检查的问题**：
   - 检查 `'date' not in selected_df.columns` **总是为 True**（因为 date 列确实被移除）
   - 导致所有正常数据都被提前返回，跳过了后续的排名计算

### 修复一：修改 `get_top_n_with_industry_constraint` 函数（第 2835-2892 行）

**修改内容**：
1. 预定义预期列结构，确保返回格式一致
2. 所有返回路径都确保返回正确格式的 DataFrame
3. 使用 `.copy()` 避免返回视图
4. 显式重建 DataFrame 确保列顺序正确

**修复后代码**：
```python
def get_top_n_with_industry_constraint(group, top_n, max_same_industry, enabled):
    """两阶段选股：候选池 top_n * 3 → 行业约束 → 最终 top_n"""
    
    # 预定义预期列结构，确保返回格式一致
    expected_columns = ['date', 'asset', 'total_score', 'industry']
    
    # 行业约束未启用或阈值为0时，直接按得分选股
    if not enabled or max_same_industry <= 0:
        result = group.nlargest(top_n, 'total_score')
        if result.empty:
            return pd.DataFrame(columns=expected_columns)
        return result.copy()
    
    # ========== 关键改进2: 候选池大小 = top_n * 3 ==========
    candidate_pool_size = min(top_n * 3, len(group))
    candidates = group.nlargest(candidate_pool_size, 'total_score')
    
    # ========== 关键改进3: 降级处理 ==========
    # 行业数据缺失时跳过约束，按得分排序选股
    if 'industry' not in candidates.columns or candidates['industry'].isna().all():
        logger.warning(f"[行业约束] 行业数据缺失，降级为纯得分选股")
        result = candidates.nlargest(top_n, 'total_score')
        if result.empty:
            return pd.DataFrame(columns=expected_columns)
        return result.copy()
    
    selected = []
    industry_count = {}
    
    for _, row in candidates.iterrows():
        if len(selected) >= top_n:
            break
        
        industry = row.get('industry')
        
        # 降级处理：行业缺失的股票直接入选
        if pd.isna(industry) or not industry or industry == '未知':
            selected.append(row)
            continue
        
        current_count = industry_count.get(industry, 0)
        if current_count < max_same_industry:
            selected.append(row)
            industry_count[industry] = current_count + 1
    
    # v3 bugfix（云舟修复 2026-05-01）：
    # 确保返回的 DataFrame 总是包含正确的列结构
    # 修复 groupby 后 date 列丢失问题
    if not selected:
        return pd.DataFrame(columns=expected_columns)
    
    # 使用 pd.DataFrame(selected) 可能导致列顺序问题，显式重建确保格式
    result_df = pd.DataFrame(selected)
    # 确保所有预期列存在
    for col in expected_columns:
        if col not in result_df.columns:
            result_df[col] = None
    return result_df[expected_columns]
```
