# IC和权重结果不变问题分析报告

## 问题现象

用户质疑：即使150天滚动窗口，昨天拉取了新IC数据（2026-04-30），今天重新计算最优权重，IC应该变化，权重应该变化，选股结果应该不同。

但实际观察到：权重不变，只有选股变化。

---

## 根本原因

**v2版本优化器因缺少psutil模块而运行失败，导致权重没有更新。**

## 为什么IC缓存没有更新到最新日期？

**这是正常的数据处理逻辑**：

1. IC计算需要前瞻收益（forward_return_1d）
2. 最新日期（2026-04-29、04-30）的数据无法计算前瞻收益（因为没有未来股价数据）
3. 所以这些日期的数据在IC计算时被自动排除

**这是正确的**：没有未来数据，就无法计算未来收益，也就无法计算IC。

---

## 结论

### 问题根源

1. **v2版本优化器运行失败**：缺少psutil模块
2. **权重没有更新**：v2使用的是昨天（4月30日）的权重
3. **选股变化**：权重不变，但每天因子数据变化，导致选股不同

### 解决方案

1. **安装psutil模块**：
   ```bash
   pip install psutil
   ```

2. **修复v2版本的依赖问题**

3. **或切换到v3版本**（修改current_version.json）
