# 需求文档：布林带%B因子开发

## 背景
布林带%B是衡量价格在布林带中位置的指标，可用于识别超买超卖信号。本需求开发%B因子的Rank IC分析、分层回测和多空策略分析功能。

---

## 1. 因子定义

### 1.1 计算公式
```
Middle Band = SMA(Close, N)
Upper Band = Middle Band + K × StdDev(Close, N)
Lower Band = Middle Band - K × StdDev(Close, N)

%B = (Close - Lower Band) / (Upper Band - Lower Band)
```

### 1.2 参数设置
| 参数 | 默认值 | 可选范围 | 说明 |
|------|--------|----------|------|
| N | 20 | [10, 30, 50] | 移动平均周期 |
| K | 2 | [1.5, 2.0, 2.5] | 标准差倍数 |

### 1.3 边界值处理
| 情况 | %B 值 | 含义 |
|------|-------|------|
| %B > 1 | > 1 | 价格突破上轨，超买信号 |
| %B = 1 | = 1 | 价格在上轨 |
| 0 < %B < 1 | (0, 1) | 价格在布林带内 |
| %B = 0 | = 0 | 价格在下轨 |
| %B < 0 | < 0 | 价格跌破下轨，超卖信号 |

### 1.4 因子特性
- **值域**：理论上无上下限（-∞, +∞）
- **均值回归**：价格倾向于回到布林带中轨
- **波动性指标**：%B 绝对值越大，价格偏离程度越大

## 2. Rank IC 分析需求

### 2.1 IC 计算方法
```python
IC = SpearmanCorrelation(因子排名, 未来N日收益率排名)
```

- 计算因子值与未来收益率的秩相关系数
- 使用 Spearman 相关性（对异常值更鲁棒）
- 预测周期：1日、5日、10日、20日

### 2.2 IC 统计指标
| 指标 | 计算方式 | 意义 |
|------|----------|------|
| IC均值 | Mean(IC_daily) | 因子预测能力 |
| IC标准差 | Std(IC_daily) | 因子稳定性 |
| ICIR | IC均值 / IC标准差 | 信息比率，> 0.05 为佳 |
| IC > 0 比例 | Count(IC>0) / Count | 预测方向正确率 |
| t统计量 | IC均值 / (IC标准差/√T) | 统计显著性 |

### 2.3 分组 IC 分析
按 %B 值分组（超买/正常/超卖），分别计算各组的 IC 表现。

## 3. 分层回测需求

### 3.1 分层设置
| 参数 | 值 | 说明 |
|------|-----|------|
| 分层数量 | 5层 | Layer 1~5 |
| 分层方法 | 按因子值排序 | 等分为5组 |
| 调仓周期 | 每日 | 每日重新分层 |

### 3.2 各层定义
| 层级 | %B 范围 | 特征 |
|------|---------|------|
| Layer 1 | 最小20% | 超卖区域 |
| Layer 2 | 20%~40% | 偏低区域 |
| Layer 3 | 40%~60% | 中性区域 |
| Layer 4 | 60%~80% | 偏高区域 |
| Layer 5 | 最大20% | 超买区域 |

### 3.3 收益统计指标
| 指标 | 说明 |
|------|------|
| 平均收益率 | 各层日均收益率 |
| 累计收益率 | 各层累计收益曲线 |
| 夏普比率 | 年化收益 / 年化波动 |
| 最大回撤 | 峰值到谷底的最大跌幅 |
| 胜率 | 正收益天数 / 总天数 |

### 3.4 多空组合收益
```
多空收益 = Layer 1 收益 - Layer 5 收益
         = 做多超卖 - 做空超买
```

## 4. 多空分析需求

### 4.1 策略定义

**策略一：超卖反弹策略**
- 做多条件：%B < 0（价格跌破下轨）
- 逻辑：超卖后价格反弹回归中轨
- 止盈：%B 回归到 0.5（中轨）

**策略二：超买回落策略**
- 做空条件：%B > 1（价格突破上轨）
- 逻辑：超买后价格回落回归中轨
- 止盈：%B 回归到 0.5（中轨）

**策略三：均值回归策略**
- 做多：%B < 0.2（接近下轨）
- 做空：%B > 0.8（接近上轨）
- 止盈：%B = 0.5

### 4.2 风险指标
| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| 年化收益 | (1+日收益)^252 - 1 | > 15% |
| 年化波动 | 日波动 × √252 | < 25% |
| 夏普比率 | (年化收益-无风险利率) / 年化波动 | > 0.6 |
| 最大回撤 | max(Peak - Valley) / Peak | < 20% |
| Calmar比率 | 年化收益 / 最大回撤 | > 0.75 |

### 4.3 胜率分析
- 信号准确率：盈利交易 / 总交易
- 盈亏比：平均盈利 / 平均亏损
- 持仓周期：平均持仓天数
