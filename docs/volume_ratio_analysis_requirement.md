# 量比因子分析总览页面需求文档

## 1. 页面概述

### 1.1 页面标题
量比(Volume Ratio 5) 因子分析总览

### 1.2 页面路由
- **前端路由**: `/volume-ratio-analysis`
- **API 路由前缀**: `/api/volume-ratio-analysis`

### 1.3 核心功能说明
整合量比因子的 Rank IC 分析与分层回测，一站式评估量比因子的预测能力。页面结构与 RSI(6) 因子分析总览保持一致，便于用户对比不同因子的表现。

## 2. 功能模块

### 2.1 Rank IC 分析

#### 2.1.1 IC 计算公式

使用 Spearman 秩相关系数计算量比因子与未来收益的相关性：

```
IC(date) = SpearmanCorr(rank(volume_ratio_5), rank(forward_return))
```

**重要**：量比因子使用**正向排名**（不反向），与 RSI(6) 不同。

| 因子 | 排名方式 | 原因 |
|------|----------|------|
| RSI(6) | 反向排名 | RSI 低 → 超卖 → 看涨 |
| 量比(5) | 正向排名 | 量比高 → 放量 → 关注度高 |

#### 2.1.2 展示指标

| 指标 | 计算方式 | 有效阈值 | 说明 |
|------|----------|----------|------|
| IC 均值 | 所有日期 IC 的平均值 | > 0.03 | 衡量因子整体预测能力 |
| ICIR | IC均值 / IC标准差 | > 0.5 | 衡量因子稳定性 |
| t 统计量 | IC均值 / (IC标准差/√n) | | 显著性检验，n为样本数 |
| p 值 | 双边检验 | < 0.05 | 统计显著性水平 |
| 正 IC 占比 | IC > 0 的天数占比 | > 50% | 因子正向预测的比例 |
| IC 标准差 | 所有日期 IC 的标准差 | < 0.1 | IC 波动性 |

#### 2.1.3 IC 时间序列图表要求

- **主图**: 每日 IC 值的折线图（采样显示，每5个点取1个）
- **副图**: 20日滚动 IC 均值曲线
- **配色**: 主线蓝色 (#00d9ff)，滚动线绿色 (#00ff88)
- **交互**: 鼠标悬停显示具体数值
- **采样**: 每5天取1个点，避免图表过密

---

### 2.2 分层回测

#### 2.2.1 分层数量

- 默认: **5层**（每层20%股票）
- 可选: **10层**（每层10%股票）

#### 2.2.2 分层逻辑

每日按量比值升序分层：

| 分层 | 排名范围 | 含义 |
|------|----------|------|
| Layer 1 | 0-20% | 量比最低（缩量） |
| Layer 2 | 20-40% | 量比偏低 |
| Layer 3 | 40-60% | 量比中等 |
| Layer 4 | 60-80% | 量比偏高 |
| Layer 5 | 80-100% | 量比最高（放量） |

**与 RSI 分层的差异**:

| 因子 | Layer 1 | Layer N |
|------|---------|---------|
| RSI(6) | 最超买（预期收益最低） | 最超卖（预期收益最高） |
| 量比(5) | 最缩量（预期收益待验证） | 最放量（预期收益待验证） |

#### 2.2.3 每层收益曲线图

- **类型**: 折线图叠加
- **数据**: 各层累计净值（初始值=1.0）
- **配色**: 
  - Layer 1: 深红 (#dc3545)
  - Layer 2: 浅红 (#fd7e14)
  - Layer 3: 黄色 (#ffc107)
  - Layer 4: 浅绿 (#5cb85c)
  - Layer 5: 深绿 (#28a745)
- **说明**: 通过颜色对比直观展示分层收益差异

#### 2.2.4 统计表格

| 列名 | 计算方式 | 说明 |
|------|----------|------|
| 分层名称 | Layer 1/N | 带含义标注 |
| 年化收益 | 日均收益 × 252 | 各层等权组合年化收益 |
| t 统计量 | 显著性检验 | 是否显著不为零 |
| p 值 | 显著性概率 | < 0.05 表示显著 |
| 夏普比率 | 年化收益 / 年化波动 | 风险调整收益 |

---

### 2.3 多空组合收益

#### 2.3.1 多空策略说明

**策略定义**:
- **做多**: Layer N（量比最高，放量组）
- **做空**: Layer 1（量比最低，缩量组）

**逻辑解释**（传统理论）:
- 放量上涨：资金关注度高，可能继续上涨
- 放量下跌：恐慌抛售，可能继续下跌
- 缩量：市场冷清，可能横盘或缓慢变化

**注意**: 量比因子需要验证其与收益的实际关系，这与 RSI 不同。

| 因子 | 多空方向 | 预期逻辑 |
|------|----------|----------|
| RSI(6) | 做多超卖，做空超买 | 反转逻辑 |
| 量比(5) | 做多放量，做空缩量 | 资金关注逻辑（需验证） |

#### 2.3.2 净值曲线图

- **类型**: 折线图
- **数据**: 多空组合累计净值
- **配色**: 紫色 (#6f42c1)
- **初始值**: 1.0
- **Y轴**: 累计净值

#### 2.3.3 关键指标

| 指标 | 有效阈值 | 说明 |
|------|----------|------|
| 年化收益 | > 0 | 多空策略盈利能力 |
| 夏普比率 | > 1 | 风险调整收益 |
| 最大回撤 | < 20% | 最大亏损幅度 |

---

### 2.4 综合指标摘要

#### 2.4.1 单调性检验

检验量比与收益的关系是否符合预期：

**检验方法**:
检查各层年化收益是否单调递增（Layer 1 → Layer N 收益递增）

| 结果 | 含义 |
|------|------|
| ✓ 通过 | 量比越高，收益越高，符合放量逻辑 |
| ✗ 未通过 | 存在反转，量比因子可能非线性 |

#### 2.4.2 因子有效性判断

综合以下指标判断因子有效性：

| 条件 | 权重 |
|------|------|
| IC均值 > 0.03 | 必须 |
| ICIR > 0.5 | 推荐 |
| 多空年化收益 > 0 | 必须 |
| 单调性检验通过 | 推荐 |
| p值 < 0.05 | 推荐 |

**判断结果**:
- **有效**: 4-5项通过
- **部分有效**: 2-3项通过
- **无效**: 0-1项通过

## 5. 与 RSI(6) 页面的差异

### 5.1 因子计算方式差异

| 因子 | 计算公式 | 数据来源 |
|------|----------|----------|
| RSI(6) | 100 - 100/(1 + RS) | 收盘价 |
| 量比(5) | 当日成交量 / 5日平均成交量 | 成交量 |

### 5.2 解读逻辑差异

#### RSI(6) 解读

| RSI值 | 含义 | 预期收益 |
|-------|------|----------|
| RSI < 30 | 超卖 | 高（反弹机会） |
| RSI > 70 | 超买 | 低（回调风险） |

**结论**: RSI 低 → 做多 → 使用反向排名

#### 量比(5) 解读

| 量比值 | 含义 | 预期收益（待验证） |
|--------|------|-------------------|
| VR > 2.5 | 剧烈放量 | 可能高（突破）或低（见顶） |
| 0.7 < VR < 1.5 | 成交正常 | 中等 |
| VR < 0.7 | 缩量 | 可能低（无人关注）或高（底部） |

**结论**: 量比因子需要验证，不确定性强，使用正向排名（待验证）

### 5.3 分层命名差异

| 分层 | RSI(6) 含义 | 量比(5) 含义 |
|------|-------------|--------------|
| Layer 1 | 最超买 | 最缩量 |
| Layer 5 | 最超卖 | 最放量 |

### 5.4 页面标题差异

| 因子 | 页面标题 |
|------|----------|
| RSI(6) | RSI(6) 因子分析总览 |
| 量比(5) | 量比(Volume Ratio 5) 因子分析总览 |

## 10. 附录

### 10.1 量比因子计算公式

```python
def calculate_volume_ratio(volume, period=5):
    """计算量比
    
    Args:
        volume: 成交量序列
        period: 均量计算周期
        
    Returns:
        量比值
    """
    avg_volume = volume.rolling(window=period).mean()
    vr = volume / avg_volume
    
    # 处理缺失值
    vr = vr.fillna(1.0)
    
    # 裁剪极值
    vr = vr.clip(0.1, 10)
    
    return vr
```

### 10.2 量比因子与收益的理论关系

**传统观点**:
- 放量上涨 → 资金涌入 → 继续上涨
- 放量下跌 → 恐慌抛售 → 继续下跌
- 缩量 → 市场冷清 → 横盘或缓慢变化

**验证观点**:
- 量比因子有效性需要通过数据验证
- 不同市场环境下可能表现不同
- 需要结合其他因子综合判断
