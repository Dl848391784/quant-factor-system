## 🛠️ 开发需求（给云舟）

### 1. KDJ_J 因子定义

#### 1.1 RSV 计算公式
```
RSV(N) = (Close_t - Low_N) / (High_N - Low_N) × 100
```
- `Close_t`：当日收盘价
- `Low_N`：N日内最低价（N日内所有 low 的最小值）
- `High_N`：N日内最高价（N日内所有 high 的最大值）

#### 1.2 K、D、J 计算公式
```
K_t = K_{t-1} × (M1-1)/M1 + RSV_t × 1/M1
D_t = D_{t-1} × (M2-1)/M2 + K_t × 1/M2
J_t = 3 × K_t - 2 × D_t
```

#### 1.3 参数说明
| 参数 | 默认值 | 说明 |
|------|--------|------|
| N | 9 | RSV 计算周期，取N日高低价 |
| M1 | 3 | K值平滑周期 |
| M2 | 3 | D值平滑周期 |

#### 1.4 初始值处理
- K_0 = 50（或使用首个RSV值）
- D_0 = 50（或使用首个K值）

#### 1.5 边界情况
- 当 `High_N == Low_N` 时，RSV = 50（避免除零）
- 数据不足 N 天时，使用可用天数计算

### 2. Rank IC 分析需求

#### 2.1 IC 计算方法
```python
IC = spearman_rank_correlation(factor_value, forward_return)
```
- 使用 Spearman 秩相关系数
- forward_return 默认为次日收益率（可配置为其他周期）
- 按日期分组计算，每天得到一个 IC 值

#### 2.2 统计指标
| 指标 | 公式 | 说明 |
|------|------|------|
| IC均值 | mean(IC_series) | 因子平均预测能力 |
| IC标准差 | std(IC_series) | IC 波动性 |
| ICIR | IC均值 / IC标准差 | 信息比率，衡量IC稳定性 |
| IC>0占比 | count(IC>0) / count(IC) | 正相关比例 |
| |IC|均值 | mean(abs(IC)) | 绝对IC强度 |

#### 2.3 IC 时序图
- X轴：日期
- Y轴：IC值
- 展示 IC 随时间变化趋势
- 添加移动平均线（如20日均线）

### 3. 分层回测需求

#### 3.1 分层配置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 层数 | 5 | 分成5组（可配置为10层） |
| 加权方式 | 等权 | 等权/市值加权可选 |
| 调仓周期 | 日频 | 每日调仓 |

#### 3.2 分层方法
1. 每日按因子值排序
2. 等分为 N 层（Layer 1 为因子最小，Layer N 为因子最大）
3. 记录每层股票组合

#### 3.3 收益统计
每层需要统计：
- 累计收益曲线
- 年化收益率
- 年化波动率
- 夏普比率
- 最大回撤
- 胜率
- 盈亏比

#### 3.4 多空组合
- 做多：Layer N（因子最大层）
- 做空：Layer 1（因子最小层）
- 多空收益 = Layer N 收益 - Layer 1 收益

### 4. 多空分析需求

#### 4.1 核心指标
| 指标 | 计算方法 | 说明 |
|------|----------|------|
| 年化收益 | (累计收益+1)^(252/days) - 1 | 多空组合年化收益 |
| 年化波动 | std(daily_return) × sqrt(252) | 日收益年化波动 |
| 夏普比率 | 年化收益 / 年化波动 | 风险调整后收益 |
| 最大回撤 | max((peak - valley) / peak) | 最大亏损幅度 |
| 卡玛比率 | 年化收益 / 最大回撤 | 收益回撤比 |
| 换手率 | 平均每日换仓比例 | 交易成本评估 |
| 胜率 | 盈利天数 / 总交易天数 | 日收益为正比例 |

#### 4.2 收益曲线
- 多空累计收益曲线
- 与基准对比（如沪深300、中证500）
- 回撤曲线
