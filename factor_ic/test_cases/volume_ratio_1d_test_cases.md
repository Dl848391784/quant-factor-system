## 测试环境

### 数据库连接要求
- 无需数据库连接（使用缓存数据文件）
- 需要文件系统访问权限

### 测试数据准备

#### 目录结构
```
cache/factor_data/
├── factor_data.json.gz    # 因子数据缓存
└── return_data.json.gz    # 收益数据缓存
```

#### 数据格式要求

**factor_data.json.gz**:
```json
{
    "data": [
        {"date": "2026-01-01", "asset": "000001.SZ", "volume_ratio_5": 1.25},
        {"date": "2026-01-01", "asset": "000002.SZ", "volume_ratio_5": 0.85},
        ...
    ]
}
```

**return_data.json.gz**:
```json
{
    "data": [
        {"date": "2026-01-01", "asset": "000001.SZ", "forward_return_1d": 0.023},
        {"date": "2026-01-01", "asset": "000002.SZ", "forward_return_1d": -0.015},
        ...
    ]
}
```

#### 最小测试数据量
- 交易日数: ≥ 20天
- 股票数量: ≥ 10只/天
- 推荐测试数据: 100个交易日 × 50只股票
