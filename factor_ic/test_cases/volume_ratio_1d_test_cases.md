    16|
    17|#### 目录结构
    18|```
    19|data_fetchers/result/

    25|
    26|**factor_data.json.gz**:
    27|```json
    28|{
    29|    "data": [
    30|        {"date": "2026-01-01", "asset": "000001.SZ", "volume_ratio_5": 1.25},
    31|        {"date": "2026-01-01", "asset": "000002.SZ", "volume_ratio_5": 0.85},
    32|        ...
    33|    ]
    34|}
    35|```
    36|
    37|**return_data.json.gz**:
    38|```json
    39|{
    40|    "data": [
    41|        {"date": "2026-01-01", "asset": "000001.SZ", "forward_return_1d": 0.023},
    42|        {"date": "2026-01-01", "asset": "000002.SZ", "forward_return_1d": -0.015},
    43|        ...
    44|    ]
    45|}
    46|```
    47|
    48|#### 最小测试数据量
    49|- 交易日数: ≥ 20天
    50|- 股票数量: ≥ 10只/天
