## 测试环境

### 数据库连接要求
- 无需数据库连接，数据来源于缓存文件
- 缓存路径: `cache/factor_data/factor_data.json.gz`
- 收益缓存: `cache/factor_data/return_data.json.gz`

### 测试数据准备
1. 确保 `factor_data.json.gz` 包含 `close` 列
2. 确保 `return_data.json.gz` 包含 `forward_return_1d` 列
3. 数据应包含至少 500 天的交易日数据
4. 股票数量不少于 10 只
5. 每只股票至少 20 天历史数据用于布林带计算

### 依赖模块
- `common.data_completeness` - 数据完整性检查

### 参数配置
- N = 20（移动平均周期）
- K = 2.0（标准差倍数）
- 内存阈值: 900MB

### TC005: %B 计算验证
**前置条件**: 
- 布林带已计算

**测试步骤**:
1. 验证 %B 公式:
   - %B = (Close - Lower) / (Upper - Lower)
2. 检查边界情况:
   - %B = 1: 价格在上轨
   - %B = 0: 价格在下轨
   - %B > 1: 突破上轨（超买）
   - %B < 0: 跌破下轨（超卖）
   - Upper == Lower: %B = 0.5

**预期结果**:
- %B 值范围正确
- 边界情况正确处理

**实际结果**: (测试时填写)
