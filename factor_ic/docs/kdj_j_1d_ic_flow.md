    67|### Step 3: KDJ_J 因子计算（核心）
    68|
    69|这是 `calculate_kdj_j_factor()` 的向量化计算流程：
    70|
    71|```
    72|calculate_kdj_j_factor(factor_df, n=9, m1=3, m2=3)
    73|    │
    74|    ├── [验证] 检查必要列 [date, asset, close, high, low]
    75|    │
    76|    ├── [排序] 按 asset + date 排序
    77|    │
    78|    ├── [Step 1] 计算 RSV（未成熟随机值）
    79|    │   │
    80|    │   ├── rolling_high = 按股票分组，过去 N 天最高价的最大值
    81|    │   ├── rolling_low = 按股票分组，过去 N 天最低价的最小值
    82|    │   │
    83|    │   └── RSV = (Close - rolling_low) / (rolling_high - rolling_low) × 100
    84|    │       │
    85|    │       └── 边界处理: 当 high==low 时，RSV = 50（避免除零）
    86|    │
    87|    ├── [Step 2] 计算 K 值（EWM 平滑）
    88|    │   │
    89|    │   ├── alpha_k = 1/M1 = 1/3
    90|    │   │
    91|    │   └── K = RSV 的 EWM(alpha=alpha_k, adjust=False)
    92|    │       │
    93|    │       └── 初始值修正: K_0 = 50 × 2/3 + RSV_0 × 1/3
    94|    │
    95|    ├── [Step 3] 计算 D 值（EWM 平滑）
    96|    │   │
    97|    │   ├── alpha_d = 1/M2 = 1/3
    98|    │   │
    99|    │   └── D = K 的 EWM(alpha=alpha_d, adjust=False)
   100|    │       │
   101|    │       └── 初始值修正: D_0 = 50 × 2/3 + K_0 × 1/3
   102|    │
   103|    ├── [Step 4] 计算 J 值
   104|    │   │
   105|    │   └── J = 3 × K - 2 × D
   106|    │
   107|    └── [统计] 输出因子统计（均值、标准差、超买超卖比例）
   108|```
   109|
   110|**KDJ_J 因子公式**：
   111|
   112|```
   113|RSV(N) = (Close_t - Low_N) / (High_N - Low_N) × 100
   114|
   115|K_t = K_{t-1} × (M1-1)/M1 + RSV_t × 1/M1
   116|D_t = D_{t-1} × (M2-1)/M2 + K_t × 1/M2
   117|J_t = 3 × K_t - 2 × D_t
   118|
   119|参数默认值：
   120|- N = 9（RSV 计算周期）
   121|- M1 = 3（K值平滑周期）
   122|- M2 = 3（D值平滑周期）
   123|- K_0 = 50, D_0 = 50（初始值）
   124|```

   128|### Step 4: IC 计算（反向排名）
   129|
   130|```
   131|calculate_kdj_j_ic(factor_df, return_df)
   132|    │
   133|    ├── [验证] 检查必需列 [date, asset, kdj_j, forward_return]
   134|    │
   135|    ├── [合并] 按键合并
   136|    │   │
   137|    │   └── merged = pd.merge(factor_df, return_df, on=[date, asset])
   138|    │
   139|    ├── [遍历] 按日期分组，逐日计算 IC
   140|    │   │
   141|    │   └─────────────────────────────────────────────┐
   142|    │   │                                             │
   143|    │   │  for each date:                              │
   144|    │   │      │                                       │
   145|    │   │      ├── 股票数 < 10? → 跳过该日              │
   146|    │   │      │                                       │
   147|    │   │      ├── J值全部相同? → IC = 0               │
   148|    │   │      │                                       │
   149|    │   │      └── 计算反向排名 IC:                     │
   150|    │   │          │                                   │
   151|    │   │          ├── [1] J值排名（升序）              │
   152|    │   │          │       rank = J.rank(pct=True, ascending=True)
   153|    │   │          │       # J最低 → rank=0, J最高 → rank=1
   154|    │   │          │                                   │
   155|    │   │          ├── [2] 反向得分                    │
   156|    │   │          │       score = 1 - rank
   157|    │   │          │       # J<0（超卖）→ score=1（最看好）
   158|    │   │          │       # J>100（超买）→ score=0（最不看好）
   159|    │   │          │                                   │
   160|    │   │          ├── [3] 收益排名（升序）            │
   161|    │   │          │       return_rank = forward_return.rank(pct=True)
   162|    │   │          │                                   │
   163|    │   │          └── [4] Spearman 相关系数          │
   164|    │   │                  │                           │
   165|    │   │                  └── IC = corr(score, return_rank)
   166|    │   │                                              │
   167|    │   └─────────────────────────────────────────────┘
   168|    │
   169|    ├── [汇总] 计算统计量
   170|    │   │
   171|    │   ├── IC均值 = ic_series.mean()
   172|    │   ├── IC标准差 = ic_series.std()
   173|    │   ├── ICIR = |IC均值| / IC标准差  # 使用绝对值（PROJECT.md 规范）
   174|    │   ├── 正比例 = IC > 0 的天数占比
   175|    │   ├── t统计量 = IC均值 / (IC标准差 / sqrt(n))
   176|    │   └── 显著性标识: *** / ** / *
   177|    │
   178|    └── 返回结果字典
   179|```

   183|### Step 5: 反向排名原理
   184|
   185|**KDJ_J 因子特殊性**：
   186|
   187|```
   188|KDJ_J 含义：
   189|┌────────────────────────────────────────────────────────────┐
   190|│  J 值范围：理论上无界限，实际常见 [-50, 150]               │
   191|│                                                            │
   192|│  - J > 100：严重超买，价格可能回调 → 不看好                 │
   193|│  - J < 0：严重超卖，价格可能反弹 → 看好                     │
   194|│  - J 在 0-100 之间：正常区间                                │
   195|│                                                            │
   196|│  因此 KDJ_J 是"反向指标":                                   │
   197|│  - J 越低 → 预期收益越高                                    │
   198|│  - J 越高 → 预期收益越低                                    │
   199|└────────────────────────────────────────────────────────────┘
   200|
   201|反向排名处理:
   202|  score = 1 - rank(J)
   203|  
   204|  示例（某日3只股票）:
   205|  | 股票 | J值 | rank(J升序) | score=1-rank | 预期含义 |
   206|  |------|-----|-------------|--------------|----------|
   207|  | A    | -20 | 0.0         | 1.0          | 最超卖,最看好 |
   208|  | B    | 50  | 0.5         | 0.5          | 中性     |
   209|  | C    | 120 | 1.0         | 0.0          | 最超买,最不看好 |
   210|```

   236|## 📊 关键指标含义
   237|
   238|| 指标 | 含义 | 判断标准 |
   239||------|------|----------|
   240|| **IC均值** | 因子预测能力 | > 0.05 = 有效；< -0.05 = 反向有效 |
   241|| **ICIR** | IC稳定性 | > 0.5 = 可用；> 1.0 = 较好；> 2.0 = 很好 |
   242|| **正比例** | IC > 0 的天数占比 | > 50% = 有预测能力 |
   243|| **t统计量** | IC是否显著不为零 | > 1.96 = 95%显著；> 2.58 = 99%显著 |
