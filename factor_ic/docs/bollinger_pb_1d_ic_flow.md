    67|### Step 3: 布林带 %B 因子计算（核心）
    68|
    69|这是 `calculate_bollinger_pb_1d_factor()` 的向量化计算流程：
    70|
    71|```
    72|calculate_bollinger_pb_1d_factor(factor_df, n=20, k=2.0)
    73|    │
    74|    ├── [验证] 检查必要列 [date, asset, close]
    75|    │
    76|    ├── [排序] 按 asset + date 排序
    77|    │
    78|    ├── [Step 1] 计算中轨（SMA）
    79|    │   │
    80|    │   ├── 按股票分组
    81|    │   │
    82|    │   └── middle_band = close.rolling(window=N, min_periods=1).mean()
    83|    │       │
    84|    │       └── N = 20（默认移动平均周期）
    85|    │
    86|    ├── [Step 2] 计算标准差
    87|    │   │
    88|    │   └── std_dev = close.rolling(window=N, min_periods=1).std()
    89|    │
    90|    ├── [Step 3] 计算上轨和下轨
    91|    │   │
    92|    │   ├── upper_band = middle_band + K × std_dev
    93|    │   │
    94|    │   └── lower_band = middle_band - K × std_dev
    95|    │       │
    96|    │       └── K = 2.0（默认标准差倍数）
    97|    │
    98|    ├── [Step 4] 计算 %B
    99|    │   │
   100|    │   ├── diff = upper_band - lower_band
   101|    │   │
   102|    │   └── %B = (close - lower_band) / diff
   103|    │       │
   104|    │       └── 边界处理: 当 diff=0 时，%B = 0.5（避免除零）
   105|    │
   106|    └── [统计] 输出因子统计（均值、标准差、超买超卖比例）
   107|```
   108|
   109|**布林带 %B 因子公式**：
   110|
   111|```
   112|Middle Band = SMA(Close, N)           # 中轨 = N日移动平均
   113|Upper Band = Middle + K × StdDev      # 上轨 = 中轨 + K倍标准差
   114|Lower Band = Middle - K × StdDev      # 下轨 = 中轨 - K倍标准差
   115|
   116|%B = (Close - Lower) / (Upper - Lower)  # 价格在布林带中的位置
   117|
   118|参数默认值：
   119|- N = 20（移动平均周期）
   120|- K = 2.0（标准差倍数）
   121|
   122|%B 含义：
   123|- %B > 1：价格突破上轨（超买）
   124|- %B = 1：价格在上轨
   125|- 0 < %B < 1：价格在布林带内
   126|- %B = 0：价格在下轨
   127|- %B < 0：价格跌破下轨（超卖）
   128|```

   132|### Step 4: IC 计算（反向排名）
   133|
   134|```
   135|calculate_bollinger_pb_1d_ic(factor_df, return_df)
   136|    │
   137|    ├── [验证] 检查必需列 [date, asset, bollinger_pb_1d, forward_return]
   138|    │
   139|    ├── [合并] 按键合并
   140|    │   │
   141|    │   └── merged = pd.merge(factor_df, return_df, on=[date, asset])
   142|    │
   143|    ├── [遍历] 按日期分组，逐日计算 IC
   144|    │   │
   145|    │   └─────────────────────────────────────────────┐
   146|    │   │                                             │
   147|    │   │  for each date:                              │
   148|    │   │      │                                       │
   149|    │   │      ├── 股票数 < 10? → 跳过该日              │
   150|    │   │      │                                       │
   151|    │   │      ├── %B值全部相同? → IC = 0              │
   152|    │   │      │                                       │
   153|    │   │      └── 计算反向排名 IC:                     │
   154|    │   │          │                                   │
   155|    │   │          ├── [1] %B排名（升序）              │
   156|    │   │          │       rank = %B.rank(pct=True, ascending=True)
   157|    │   │          │       # %B最低 → rank=0, %B最高 → rank=1
   158|    │   │          │                                   │
   159|    │   │          ├── [2] 反向得分                    │
   160|    │   │          │       score = 1 - rank
   161|    │   │          │       # %B<0（超卖）→ score=1（最看好）
   162|    │   │          │       # %B>1（超买）→ score=0（最不看好）
   163|    │   │          │                                   │
   164|    │   │          ├── [3] 收益排名（升序）            │
   165|    │   │          │       return_rank = forward_return.rank(pct=True)
   166|    │   │          │                                   │
   167|    │   │          └── [4] Spearman 相关系数          │
   168|    │   │                  │                           │
   169|    │   │                  └── IC = corr(score, return_rank)
   170|    │   │                                              │
   171|    │   └─────────────────────────────────────────────┘
   172|    │
   173|    ├── [汇总] 计算统计量
   174|    │   │
   175|    │   ├── IC均值 = ic_series.mean()
   176|    │   ├── IC标准差 = ic_series.std()
   177|    │   ├── ICIR = |IC均值| / IC标准差  # 使用绝对值（PROJECT.md 规范）
   178|    │   ├── 正比例 = IC > 0 的天数占比
   179|    │   ├── t统计量 = IC均值 / (IC标准差 / sqrt(n))
   180|    │   └── 显著性标识: *** / ** / *
   181|    │
   182|    └── 返回结果字典
   183|```

   187|### Step 5: 反向排名原理
   188|
   189|**布林带 %B 因子特殊性**：
   190|
   191|```
   192|%B 含义：
   193|┌────────────────────────────────────────────────────────────┐
   194|│  %B 反映价格相对于布林带的位置：                            │
   195|│                                                            │
   196|│  - %B > 1：价格突破上轨，严重超买 → 预期回落 → 不看好       │
   197|│  - %B < 0：价格跌破下轨，严重超卖 → 预期反弹 → 看好         │
   198|│  - 0 < %B < 1：价格在布林带内，正常区间                     │
   199|│                                                            │
   200|│  因此 %B 是"反向指标":                                      │
   201|│  - %B 越低 → 预期收益越高                                   │
   202|│  - %B 越高 → 预期收益越低                                   │
   203|└────────────────────────────────────────────────────────────┘
   204|
   205|反向排名处理:
   206|  score = 1 - rank(%B)
   207|  
   208|  示例（某日3只股票）:
   209|  | 股票 | %B  | rank(%B升序) | score=1-rank | 预期含义 |
   210|  |------|-----|--------------|--------------|----------|
   211|  | A    | -0.1| 0.0          | 1.0          | 跌破下轨,最看好 |
   212|  | B    | 0.5 | 0.5          | 0.5          | 在布林带中间 |
   213|  | C    | 1.2 | 1.0          | 0.0          | 突破上轨,最不看好 |
   214|```

   240|## 📊 关键指标含义
   241|
   242|| 指标 | 含义 | 判断标准 |
   243||------|------|----------|
   244|| **IC均值** | 因子预测能力 | > 0.05 = 有效；< -0.05 = 反向有效 |
   245|| **ICIR** | IC稳定性 | > 0.5 = 可用；> 1.0 = 较好；> 2.0 = 很好 |
   246|| **正比例** | IC > 0 的天数占比 | > 50% = 有预测能力 |
   247|| **t统计量** | IC是否显著不为零 | > 1.96 = 95%显著；> 2.58 = 99%显著 |
