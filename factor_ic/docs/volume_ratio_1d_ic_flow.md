    63|### Step 2: IC 计算（正向排名）
    64|
    65|这是 `calculate_daily_ic_series()` 的核心流程：
    66|
    67|```
    68|calculate_daily_ic_series(factor_df, return_df)
    69|    │
    70|    ├── [合并] 按键合并
    71|    │   │
    72|    │   └── merged = pd.merge(
    73|    │       factor_df[['date', 'asset', 'volume_ratio_5']],
    74|    │       return_df[['date', 'asset', 'forward_return']],
    75|    │       on=['date', 'asset']
    76|    │   )
    77|    │
    78|    ├── [遍历] 按日期分组，逐日计算 IC
    79|    │   │
    80|    │   └─────────────────────────────────────────────┐
    81|    │   │                                             │
    82|    │   │  for each date:                              │
    83|    │   │      │                                       │
    84|    │   │      ├── 股票数 < 10? → 跳过该日              │
    85|    │   │      │                                       │
    86|    │   │      └── 计算正向排名 IC（Spearman）:         │
    87|    │   │          │                                   │
    88|    │   │          └── IC = spearmanr(volume_ratio_5, forward_return)
    89|    │   │              │                               │
    90|    │   │              └── scipy.stats.spearmanr 直接计算
    91|    │   │                  # 量比高 → 排名高 → 预期收益高
    92|    │   │                                              │
    93|    │   └─────────────────────────────────────────────┘
    94|    │
    95|    ├── [滚动均值] 计算 20 日滚动 IC 均值
    96|    │   │
    97|    │   └── rolling_mean = ic_series.rolling(window=20, min_periods=1).mean()
    98|    │
    99|    ├── [统计量计算]
   100|    │   │
   101|    │   ├── IC均值 = ic_series.mean()
   102|    │   ├── IC标准差 = ic_series.std()
   103|    │   ├── ICIR = |IC均值| / IC标准差  # 使用绝对值（PROJECT.md 规范）
   104|    │   ├── 正比例 = IC > 0 的天数占比
   105|    │   ├── t统计量 = IC均值 × sqrt(n) / IC标准差
   106|    │   └
   107|    │   └── 显著性判断:
   108|    │       │
   109|    │       ├── |t_stat| > 2.576 → "***"（99%显著）
   110|    │       ├── |t_stat| > 1.96 → "**"（95%显著）
   111|    │       ├── |t_stat| > 1.645 → "*"（90%显著）
   112|    │       └── 否则 → 无星号
   113|    │
   114|    └── 返回结果字典
   115|```

   119|### Step 3: 正向排名原理
   120|
   121|**量比因子特殊性**：
   122|
   123|```
   124|量比因子含义：
   125|┌────────────────────────────────────────────────────────────┐
   126|│  volume_ratio_5 = 当日成交量 / 过去5日平均成交量            │
   127|│                                                            │
   128|│  - 量比 > 1：当日成交量高于近期均值 → 资金关注度提升         │
   129|│  - 量比 < 1：当日成交量低于近期均值 → 资金关注度降低         │
   130|│                                                            │
   131|│  量比是"正向指标":                                           │
   132|│  - 量比越高 → 资金关注度越高 → 预期收益越高                  │
   133|│  - 量比越低 → 资金关注度越低 → 预期收益越低                  │
   134|│                                                            │
   135|│  因此使用正向排名，无需反向处理                              │
   136|└────────────────────────────────────────────────────────────┘
   137|
   138|直接计算 Spearman IC:
   139|  IC = spearmanr(volume_ratio_5, forward_return)
   140|  
   141|  示例（某日3只股票）:
   142|  | 股票 | 量比 | 收益 | 排名关系 |
   143|  |------|------|------|----------|
   144|  | A    | 2.5  | 5%   | 量比高,收益高 → 正相关贡献 |
   145|  | B    | 1.0  | 2%   | 量比中,收益中 → 中性 |
   146|  | C    | 0.5  | -1%  | 量比低,收益低 → 正相关贡献 |
   147|```

   181|## 📊 关键指标含义
   182|
   183|| 指标 | 含义 | 判断标准 |
   184||------|------|----------|
   185|| **IC均值** | 因子预测能力 | > 0.05 = 有效；< -0.05 = 反向有效 |
   186|| **ICIR** | IC稳定性 | > 0.5 = 可用；> 1.0 = 较好；> 2.0 = 很好 |
   187|| **正比例** | IC > 0 的天数占比 | > 50% = 有预测能力 |
   188|| **t统计量** | IC是否显著不为零 | > 1.96 = 95%显著；> 2.58 = 99%显著 |
