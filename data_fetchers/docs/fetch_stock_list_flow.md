## 详细流程

### Step 1: 获取股票列表

**输入**: 新浪财经 API 端点

**处理**:
1. 创建 Session（复用 http_client.py）
2. 分页请求沪市A股(sh_a)和深市A股(sz_a)
3. 每页80条，自动重试3次
4. 去重并按代码排序

**输出**:
```json
[
  {"code": "600000", "name": "浦发银行", "market": "sh"},
  {"code": "000001", "name": "平安银行", "market": "sz"},
  ...
]
```

### Step 2: 筛选主板股票

**筛选规则**:

| 类别 | 规则 | 示例 |
|------|------|------|
| 保留 | 沪市主板(60开头) | 600000 |
| 保留 | 深市主板(00开头) | 000001 |
| 剔除 | 创业板(30开头) | 300001 |
| 剔除 | 科创板(688开头) | 688001 |
| 剔除 | 北交所(8/4开头) | 830001 |
| 剔除 | ST类股票 | ST康美 |
| 剔除 | 退市股票 | 退市海润 |

### Step 3: 增量更新缓存

**增量逻辑**:
- 新增：API有但缓存没有 → 添加
- 删除：缓存有但API没有 → 删除（退市/ST）
- 保留：两边都有 → 保留

**新增股票添加 `added_at` 字段**:
```json
{
  "code": "601234",
  "name": "新股票",
  "market": "sh",
  "added_at": "2026-05-27"
}
```

### Step 4: 数据验证

**验证检查项**:

| 检查项 | 阈值 | 说明 |
|-------|------|------|
| 总数最低 | 2500 | 少于此值为异常 |
| 总数警告 | 2800 | 少于此值输出警告 |
| 沪市最低 | 1500 | 沪市主板预期 |
| 深市最低 | 1200 | 深市主板预期 |
| ST混入 | 0 | 不允许ST股票 |
| 创业板混入 | 0 | 不允许创业板 |
| 科创板混入 | 0 | 不允许科创板 |
| 北交所混入 | 0 | 不允许北交所 |
