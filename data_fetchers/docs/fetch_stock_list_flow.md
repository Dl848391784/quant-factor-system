    83|## 关键函数说明
    84|
    85|### fetch_stocks_from_sina()
    86|
    87|**功能**: 从新浪财经API分页获取主板股票列表
    88|
    89|**流程**:
    90|1. 使用 `create_sina_session()` 创建HTTP客户端
    91|2. 分页获取沪市A股(sh_a)和深市A股(sz_a)
    92|3. 使用 `is_valid_main_board_stock()` 筛选主板股票
    93|4. 使用 `determine_market()` 判断所属市场
    94|5. 去重 + 按代码排序
    95|
    96|**返回**: `(stocks: List[Dict], api_pages: int)`
    97|
    98|---
    99|
   100|### save_cache()
   101|
   102|**功能**: 增量更新股票列表持久化文件
   103|
   104|**增量逻辑**:
   105|- **新增**: API有但文件没有 → 添加（标记added_at）
   106|- **删除**: 文件有但API没有 → 删除（退市/ST）
   107|- **更新**: 两边都有 → 同步name字段（最新名称）
   108|
   109|**输出文件**:
   110|- `data_fetchers/result/stock_list.json` - 股票列表数据
   111|- `result/stock_list_meta.json` - 元信息
   112|
   113|**写入方式**: 使用 `write_json_cache()` 原子写入（v2.9新增）
   114|
   115|---
   116|
   117|### validate_cache()
   118|
   119|**功能**: 验证缓存数据完整性
   120|
   121|**检查项**:
   122|1. 数量检查：总股票数 >= MIN_TOTAL_STOCKS (2500)
   123|2. ST股票混入检查：使用前缀匹配（S开头、*ST、ST）
   124|3. 创业板混入检查：30开头
   125|4. 科创板混入检查：688开头
   126|5. 北交所混入检查：8开头、4开头
   127|6. 市场分布检查：沪市 >= 1500，深市 >= 1200
   128|7. 数据格式检查：抽查前10条（code、name、market）
   129|
   130|---
   131|
   132|### is_valid_main_board_stock()
   133|
   134|**功能**: 判断是否为有效主板股票
   135|
   136|**剔除规则**:
   137|1. 创业板（30开头）
   138|2. 科创板（688开头）
   139|3. 北交所（8开头、4开头）
   140|4. ST类股票（前缀匹配，使用ST_PREFIXES常量）
   141|   - S开头：历史特殊处理股票（SST、S*ST）
   142|   - *ST：退市风险警示（不以S开头）
   143|   - ST：风险警示（不以S开头）
   144|5. 退市股票（名称含"退市"）
   145|
   146|**保留规则**:
   147|- 沪市主板（60开头）
   148|- 深市主板（00开头，含003）

   153|
   154|### write_json_cache 替换手写原子写入
   155|
   156|**修改位置**: save_cache() 函数（678行、686行）
   157|
   158|**修改前**:
   159|```python
   160|_write_json_file(CACHE_FILE, cache_data, _logger)
   161|_write_json_file(RESULT_FILE, result_data, _logger)
   162|```
   163|
   164|**修改后**:
   165|```python
   166|write_json_cache(CACHE_FILE, cache_data, json_indent=2, logger=_logger)
   167|write_json_cache(RESULT_FILE, result_data, json_indent=2, logger=_logger)
   168|```
   169|
   170|**优势**:
   171|- 复用公共模块原子写入实现（tempfile.NamedTemporaryFile + os.replace）
   172|- 删除冗余函数 `_write_json_file`（减少45行代码）
   173|- 符合 MODULE.md 约束 #4（强制复用公共模块）
