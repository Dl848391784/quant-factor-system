   129|## 缓存机制
   130|
   131|### 主缓存（akshare数据）
   132|
   133|**路径**: `result/stock_industry.json`
   134|
   135|**有效期**: 7天
   136|
   137|**结构**:
   138|```json
   139|{
   140|  "meta": {
   141|    "version": "2.4",
   142|    "source": "sw_category",
   143|    "level": "一级",
   144|    "updated_at": "2026-05-27",
   145|    "total_count": 5234
   146|  },
   147|  "industries": {
   148|    "000001": {
   149|      "name": "平安银行",
   150|      "industry": "银行",
   151|      "industry_code": "4801"
   152|    },
   153|    ...
   154|  }
   155|}
   156|```
   157|
   158|**更新策略**:
   159|- 缓存过期（>7天）时尝试刷新
   160|- 刷新失败时**降级使用旧缓存**（而非直接切换备用）
   161|- 写入使用 `write_json_cache()`（原子写入）
   162|
   163|### 备用缓存（本地推断）
   164|
   165|**路径**: 同 `result/stock_industry.json`（覆盖主缓存）
   166|
   167|**触发条件**: akshare API 完全失败
   168|
   169|**数据源**: `data_fetchers/result/stock_list.json`
   170|
   171|**推断方式**: 名称关键词匹配（`infer_industry_from_name()`）
   172|
   173|**写入策略**:
   174|- 备用缓存写入失败为**非致命错误**（warning）
   175|- 下次调用会重新读取备用数据源
   176|- 与主缓存写入策略不同（主缓存失败抛异常）
   177|

   180|## 错误处理策略
   181|
   182|### 错误分类与处理
   183|
   184|| 错误类型 | 处理策略 | 日志级别 | 说明 |
   185||---------|---------|---------|------|
   186|| akshare API 失败 | 降级备用数据 | warning | 非致命，切换本地推断 |
   187|| 缓存文件损坏 | 删除+重新获取 | warning | 数据完整性检查失败 |
   188|| 缓存过期刷新失败 | 降级旧缓存 | warning | 保留旧数据而非备用 |
   189|| 备用缓存写入失败 | 忽略（warning） | warning | 非致命，下次重试 |
   190|| 主缓存写入失败 | 抛异常 | error | 致命错误，影响后续流程 |
   191|| 列名校验失败 | 抛 KeyError | error | API 返回格式异常 |
   192|| 日期解析失败 | 使用现有缓存 | warning | 格式异常不阻塞 |
   193|
   194|### 降级策略优先级
   195|
   196|```
   197|1. 主缓存（akshare数据，最新）
   198|   ↓ [过期]
   199|2. 刷新缓存（尝试获取新数据）
   200|   ↓ [失败]
   201|3. 旧缓存（保留过期数据）
   202|   ↓ [不存在]
   203|4. 备用数据（本地推断，准确性低）
   204|```
   205|
   206|**关键决策**:
   207|- 优先使用过期缓存而非备用数据
   208|- 备用数据准确性低于 akshare，仅作兜底

   212|## 线程安全设计
   213|
   214|### 模块级缓存（DCL双重检查）
   215|
   216|```python
   217|_industry_cache = None           # 模块级缓存
   218|_cache_lock = threading.Lock()   # 线程锁
   219|
   220|def get_industry_map():
   221|    global _industry_cache
   222|    if _industry_cache is None:         # 第一次检查（无锁）
   223|        with _cache_lock:               # 加锁
   224|            if _industry_cache is None: # 第二次检查（锁内）
   225|                _industry_cache = load_stock_industry()
   226|    return _industry_cache
   227|```
   228|
   229|**DCL优势**:
   230|- 避免锁竞争（缓存已加载时无锁访问）
   231|- 避免重复加载（锁内二次检查）
   232|- 线程安全（并发访问安全）

   309|## 行业代码映射
   310|
   311|### 申万2021一级分类（31个行业）
   312|
   313|**映射规则**:
   314|- akshare 返回的 `industry_code` 为4位（如 `4801`）
   315|- 前2位为一级代码（如 `48`）
   316|- 使用 `SW_INDUSTRY_CODE_MAP` 映射到行业名称
   317|
   318|**特殊处理**:
   319|- 不存在的一级代码（如 `22`, `28`, `33`）映射到 `'其他'`
   320|- 未匹配的行业代码默认 `'其他'`
   321|
   322|**一级代码范围**: 
   323|```
   324|11, 21, 23-27, 31-32, 34-36, 41-46, 48-49, 62-65, 71-77
   325|```

   329|## 关键词推断逻辑
   330|
   331|### infer_industry_from_name()
   332|
   333|**模糊匹配规则**:
   334|- 关键词包含检测（非精确匹配）
   335|- 遍历顺序决定优先级
   336|- 具体关键词优先（避免歧义）
   337|
   338|**关键词重叠消除**:
   339|- `光伏`/`风电` 只在 `电力` 中
   340|- `新能源` 使用 `锂电`/`电池`/`太阳能`
   341|- 品牌词已移除（"平安"、"中信"不作为行业推断依据）
   342|
   343|**示例**:
   344|- `"平安银行"` → `"银行"`（匹配 `"银行"`）
   345|- `"新能源电力"` → `"电力"`（匹配 `"电力"`，电力在字典中先于新能源）
