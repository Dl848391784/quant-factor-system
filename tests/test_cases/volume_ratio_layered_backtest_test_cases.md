## 测试环境

### 数据库连接要求
- 无需数据库连接，数据来源于缓存文件
- 因子缓存路径: `cache/factor_data/factor_data.json.gz`
- 收益缓存路径: `cache/factor_data/return_data.json.gz`

### 测试数据准备
1. 确保 `factor_data.json.gz` 包含 `volume_ratio_5` 列
2. 确保 `return_data.json.gz` 包含 `forward_return` 列
3. 数据应包含至少 500 天的交易日数据
4. 股票数量不少于 100 只（满足10层分层，每层至少10只）

### 依赖模块
- `backtest.layered_backtest` - LayeredBacktestEngine 类
- `factor_ic.common` - 通用数据处理模块

import pandas as pd
import numpy as np

def create_test_data(n_days=500, n_stocks=100):
    dates = pd.date_range('2025-01-01', periods=n_days)
    assets = [f'stock_{i}' for i in range(n_stocks)]
    
    factor_data = []
    for date in dates:
        for asset in assets:
            factor_data.append({
                'date': date,
                'asset': asset,
                'volume_ratio_5': np.random.lognormal(0, 0.5)
            })
    
    return pd.DataFrame(factor_data)
