     9|## 1. 因子概述
    10|
    11|### 1.1 因子定义
    12|
    13|KDJ_J 因子是 KDJ 指标的 J 值，计算公式：
    14|
    15|```
    16|RSV = (Close - LowN) / (HighN - LowN) * 100
    17|K = EMA(RSV, m1)  （首次用50）
    18|D = EMA(K, m2)    （首次用50）
    19|J = 3K - 2D
    20|```
    21|
    22|其中：
    23|- `N = 9`: RSV 计算周期
    24|- `M1 = 3`: K 值平滑周期
    25|- `M2 = 3`: D 值平滑周期
    26|
    27|### 1.2 因子特性
    28|
    29|| 特性 | 描述 |
    30||------|------|
    31|| 理论范围 | -∞ ~ +∞（可超出 0-100） |
    32|| 实测范围 | -28.62 ~ 128.78 |
    33|| 超买信号 | J > 100 |
    34|| 超卖信号 | J < 0 |
    35|
    36|### 1.3 IC 分析结果
    37|
    38|```json
    39|{
    40|  "ic_mean": -0.01518764980544747,
    41|  "factor_direction": "反向因子：分层回测时做多低值组、做空高值组",
    42|  "statistical_significance": true
    43|}
    44|```
    45|
    46|**结论**: IC 绝对值 < 0.03，预测能力较弱，但统计显著。

    51|
    52|### 2.1 分层阈值
    53|
    54|```python
    55|layer_thresholds = [-30, 0, 20, 80, 100, 130]
    56|```
    57|
    58|**分层定义**:
    59|
    60|| Layer | 阈值范围 | 名称 | 含义 |
    61||-------|----------|------|------|
    62|| 1 | J < 0 | 超卖层 | 极度超卖 |
    63|| 2 | 0 ≤ J < 20 | 偏下层 | 超卖倾向 |
    64|| 3 | 20 ≤ J < 80 | 中性层 | 中性区间 |
    65|| 4 | 80 ≤ J < 100 | 偏上层 | 超买倾向 |
    66|| 5 | J ≥ 100 | 超买层 | 极度超买 |
    67|
    68|### 2.2 多空组合
    69|
    70|```python
    71|factor_direction = 'negative'  # 反向因子
    72|long_layers = [1, 2]   # 做多超卖层
    73|short_layers = [4, 5]  # 做空超买层
    74|```
    75|
    76|**策略逻辑**: 
    77|- 反向因子，做多低值组（超卖），做空高值组（超买）
    78|- 符合 KDJ 指标的传统用法：超卖反弹、超买回调

    89|## 3. 脚本实现
    90|
    91|### 3.1 文件位置
    92|
    93|```
    94|backtest/layered_backtest_kdj_j_1d.py
    95|```
    96|
    97|### 3.2 核心函数
    98|
    99|#### `calculate_kdj_j(factor_df, n=9, m1=3, m2=3)`
   100|
   101|**计算步骤**:
   102|1. 按 asset+date 排序
   103|2. 计算 n 日滚动最高价 HighN 和最低价 LowN
   104|3. 计算 RSV = (Close - LowN) / (HighN - LowN) * 100
   105|4. 使用 EWM 计算 K（初始值 50）
   106|5. 使用 EWM 计算 D（初始值 50）
   107|6. 计算 J = 3K - 2D
   108|
   109|**注意事项**:
   110|- 函数入口必须先 `.copy()`
   111|- KDJ 是单股票时序指标，必须按 asset 分组
   112|- `rolling(min_periods=n)` 导致前 n-1 天为 NaN
   113|
   114|#### `run_kdj_j_layered_backtest()`
   115|
   116|**执行流程**:
   117|```
   118|1. 加载配置 KDJJLayerConfig
   119|2. 从缓存加载因子数据和收益数据
   120|3. 计算 KDJ_J 因子
   121|4. 创建回测引擎 LayeredBacktestEngine
   122|5. 执行分层回测
   123|6. 生成报告
   124|7. 保存结果
   125|```
   126|
   127|### 3.3 运行命令
   128|

   208|## 7. 注意事项
   209|
   210|### 7.1 KDJ 计算陷阱
   211|
   212|1. **初始值问题**: EWM 计算需要虚拟初始值 50
   213|2. **排序问题**: 必须 asset+date 排序，否则跨股票混合
   214|3. **NaN 处理**: 前 n-1 天为 NaN，回测时自动过滤
   215|
   216|### 7.2 边界处理
   217|
   218|实测 J 值范围 -28.62 ~ 128.78，阈值设计需覆盖：
   219|- 下界: -30（实测最小值向下取整）
   220|- 上界: 130（实测最大值向上取整）
   221|
   222|### 7.3 IC 较弱的因子
   223|
   224|KDJ_J 因子 IC 绝对值 < 0.03：
   225|- 单独使用效果有限
