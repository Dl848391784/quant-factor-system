## 一、概述

本文档记录 `layered_backtest_bollinger_pb_1d.py` 的分层回测流程。

**因子说明：**
- Bollinger %B = (Price - Lower) / (Upper - Lower)
- %B < 0：价格在下轨之下（超卖）
- %B > 1：价格在上轨之上（超买）

**因子方向：** 反向因子（IC结果: ic_mean = -0.04）

---

## 二、配置参数

### 分层阈值（fixed_threshold 模式）

| 层级 | 阈值范围 | 说明 |
|------|---------|------|
| Layer1 | %B < 0 | 超卖层（价格在下轨之下） |
| Layer2 | 0 ≤ %B < 0.25 | 偏下轨 |
| Layer3 | 0.25 ≤ %B < 0.5 | 中性偏下 |
| Layer4 | 0.5 ≤ %B < 0.75 | 中性偏上 |
| Layer5 | 0.75 ≤ %B < 1 | 接近上轨 |
| Layer6 | %B ≥ 1 | 超买层（价格在上轨之上） |

### 多空组合（反向因子）

| 组合 | 层级 | 说明 |
|------|------|------|
| 多头 | Layer1, Layer2 | 超卖+偏下（预期高收益） |
| 空头 | Layer5, Layer6 | 近上轨+超买（预期低收益） |

### 布林带参数

| 参数 | 值 | 说明 |
|------|---|------|
| N | 20 | 移动平均周期 |
| K | 2.0 | 标差倍数 |

### 其他参数

| 参数 | 值 |
|------|---|
| 因子方向 | negative |
| 交易成本率 | 0.30%（单边） |
| 最小股票数 | 10 |

## 四、因子计算流程

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: 计算 Bollinger PB 因子                                   │
│  ─────────────────────────────────────────────────────────────── │
│  1. 按 asset 分组计算 rolling MA(n) 和 Std(n)                     │
│  2. Upper = MA + K * Std                                          │
│  3. Lower = MA - K * Std                                          │
│  4. %B = (Close - Lower) / (Upper - Lower)                        │
│  5. 防止除零：band_width=0 时 %B=0.5                               │
│  6. min_periods=n：前 n-1 天为 NaN                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 八、边界警告说明

实测因子范围 -0.552 ~ 1.559 超出阈值范围 -0.5 ~ 1.5。

边界外数据（%B < -0.5）归入 Layer1，符合 MODULE.md 边界处理规范。

建议：可调整阈值为 [-0.6, 0, 0.25, 0.5, 0.75, 1, 1.6] 以覆盖更宽范围。

## 九、结论

Bollinger PB 作为反向因子的分层回测已完成。

**注意事项：**
- 超买层（Layer6）收益最高（年化66.74%），与反向因子假设矛盾
- 多空组合收益为负（-22.49%），说明反向因子策略在此数据集上不理想
- 建议重新审视因子方向假设，或调整多空组合配置
