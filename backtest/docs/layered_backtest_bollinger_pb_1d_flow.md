     9|## 一、概述
    10|
    11|本文档记录 `layered_backtest_bollinger_pb_1d.py` 的分层回测流程。
    12|
    13|**因子说明：**
    14|- Bollinger %B = (Price - Lower) / (Upper - Lower)
    15|- %B < 0：价格在下轨之下（超卖）
    16|- %B > 1：价格在上轨之上（超买）
    17|
    18|**因子方向：** 反向因子（IC结果: ic_mean = -0.04）
    19|

    22|## 二、配置参数
    23|
    24|### 分层阈值（fixed_threshold 模式）
    25|
    26|| 层级 | 阈值范围 | 说明 |
    27||------|---------|------|
    28|| Layer1 | %B < 0 | 超卖层（价格在下轨之下） |
    29|| Layer2 | 0 ≤ %B < 0.25 | 偏下轨 |
    30|| Layer3 | 0.25 ≤ %B < 0.5 | 中性偏下 |
    31|| Layer4 | 0.5 ≤ %B < 0.75 | 中性偏上 |
    32|| Layer5 | 0.75 ≤ %B < 1 | 接近上轨 |
    33|| Layer6 | %B ≥ 1 | 超买层（价格在上轨之上） |
    34|
    35|### 多空组合（反向因子）
    36|
    37|| 组合 | 层级 | 说明 |
    38||------|------|------|
    39|| 多头 | Layer1, Layer2 | 超卖+偏下（预期高收益） |
    40|| 空头 | Layer5, Layer6 | 近上轨+超买（预期低收益） |

    74|## 四、因子计算流程
    75|
    76|```
    77|┌─────────────────────────────────────────────────────────────────┐
    78|│  Step 2: 计算 Bollinger PB 因子                                   │
    79|│  ─────────────────────────────────────────────────────────────── │
    80|│  1. 按 asset 分组计算 rolling MA(n) 和 Std(n)                     │
    81|│  2. Upper = MA + K * Std                                          │
    82|│  3. Lower = MA - K * Std                                          │
    83|│  4. %B = (Close - Lower) / (Upper - Lower)                        │
    84|│  5. 防止除零：band_width=0 时 %B=0.5                               │
    85|│  6. min_periods=n：前 n-1 天为 NaN                                 │
    86|└─────────────────────────────────────────────────────────────────┘
    87|```
