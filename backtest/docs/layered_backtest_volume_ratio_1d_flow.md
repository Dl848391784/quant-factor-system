## 1. 因子概述

### 1.1 因子定义

量比因子衡量当日成交量相对于历史均值的变化程度：

```
volume_ratio_5 = 当日成交量 / 过去 5 日平均成交量
```

其中：
- 数据已在缓存中，无需额外计算
- 因子值恒 ≥ 0

### 1.2 因子特性

| 特性 | 描述 |
|------|------|
| 理论范围 | ≥ 0（无上界） |
| 实测范围 | 0.1 ~ 4.97 |
| 正常值 | ratio ≈ 1（当日成交量等于历史均值） |
| 放量信号 | ratio > 1（成交量高于均值） |
| 缩量信号 | ratio < 1（成交量低于均值） |

```json
  "factor_direction": "反向因子：分层回测时做多低值组、做空高值组",

```

**结论**: IC 绝对值 > 0.03，有一定预测能力，统计显著。

## 2. 分层配置

### 2.1 分层阈值

```python
layer_thresholds = [0, 0.5, 1.0, 1.5, 2.0, 5.0]
```

**分层定义**:

| Layer | 阈值范围 | 名称 | 含义 |
|-------|----------|------|------|
| 1 | ratio < 0.5 | 极缩量层 | 成交量远低于均值 |
| 2 | 0.5 ≤ ratio < 1 | 缩量层 | 成交量低于均值 |
| 3 | 1 ≤ ratio < 1.5 | 正常层 | 成交量接近均值 |
| 4 | 1.5 ≤ ratio < 2 | 放量层 | 成交量偏高 |
| 5 | ratio ≥ 2 | 极放量层 | 成交量极放量 |

### 2.2 多空组合

```python
factor_direction = 'negative'  # 反向因子
long_layers = [1, 2]   # 做多缩量组
short_layers = [4, 5]  # 做空放量组
```

**策略逻辑**: 
- 反向因子，做多缩量组，做空放量组
- IC 为负说明高放量预期低收益（过度交易后回调）

### 2.3 其他参数

| 参数 | 值 | 说明 |
|------|-----|------|
| trade_cost_rate | 0.003 | 交易成本 0.3% |
| min_stocks_per_layer | 10 | 每层最小股票数 |
